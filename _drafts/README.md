# Design drafts — not served

Claude Design canvas sources (*.dc.html) and their runtime (support.js,
doc-page.js), parked here for future development and re-import into a
design canvas. GitHub Pages' Jekyll build excludes underscore-prefixed
folders, so nothing in _drafts/ appears on the live site.

To re-activate a design workflow: seed a Claude Design canvas from these
artboards, refine visually, then port changes into the production pages.

Unlisted projects (hidden from listings but reachable by direct URL) are
controlled separately: set "hidden": true/false in content/projects/<slug>.json.
